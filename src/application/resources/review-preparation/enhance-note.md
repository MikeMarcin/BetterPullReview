# Enhance a note

Improve the wording of a private note the reviewer wrote for themselves while reading a pull request. Keep every point, question and reminder it holds, and its meaning. Make it easy to read later: short sentences, one thought per line where the note is a list, the most important point first.

Keep code, paths, line references and links as written. Do not add findings, conclusions or tasks the note does not contain, and do not turn it into a comment addressed to the author. With a selection, rewrite only that fragment and keep everything outside it.

Return the required structured result only.
