# Tour outline

Suggest a small conceptual route that helps a reviewer understand and challenge this change. Begin with the failure/contract or main decision that makes the rest intelligible, not automatically the first file in alphabetical order. An idea can span files; a file can contain several stops.

Use only supplied resolvable source candidates. Prefer important decisions, boundaries, non-obvious unchanged context and evidence over mechanical edit coverage. There is no target number of stops or requirement for every file. Avoid overlapping/redundant candidates when one stop with related locations is clearer.

For each entry return a short idea-focused title, a supplied primary source-reference ID, optional supplied related IDs, one brief private reason and an optional question for the author. Do not write the publishable comment body. Do not write a full PR description, a narrative tour, Ready flags or tool actions.

Missing intent is a question for the author, not permission to invent rationale. The author must visit and complete every retained entry. Return the structured outline result and nothing else.
