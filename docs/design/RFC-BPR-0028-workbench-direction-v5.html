Modalities, not automatic collapsing. Overview, Read, Review and Discuss are presets for which drawers are open: Read keeps the file tree collapsed and comments open beside the code; Review opens the file tree too; Discuss widens the comments. A preset is chosen from the strip or by ⌘1 to ⌘4 and stays until you change it. Automatic transitions are off by default and configured in Settings, for example "opening a PR shows Overview" and "starting to read from Overview enters Read". The epoch line's handles drag; click a node to compare from it, ⌘-click to compare to it, right-click for the menu shown. The amber tick is my last review; its tooltip says so.
