The proposal: set up in the tab

The first time the Agent tab opens, it is a four-step setup instead of a conversation. Agent finds the agents by reading file metadata, shows each with its path, and chooses the one it found. Repository finds your clone of the pull request's repository in the clone folders you list in Settings (reading .git/config only), and remembers the one you pick. Check it works checks the agent answers and makes the agent's own worktree of your clone at the head, each result in words with a recovery. Ready folds the steps to one green line, shows what the agent gets, and puts the cursor in the question field. A later pull request in another repository asks only the Repository step. The agent's worktree never touches your checkout or branches and is removed when its session ends.
