Start a review, as GitHub has it

Today a draft in the drawer has one way out: Publish, which posts that comment on its own at once. Compose review sends only a summary, so its Comment needs text. These frames add GitHub's second way: keep comments pending in a review, then finish the review once.

What building it takes

  • A pending mark on a draft, kept with the draft on this computer, and every pending draft of the pull request shown at its line, not only the selected line's.
  • The review submission carries the pending comments as GitHub's review comments, and marks each one published only when the review is accepted.
  • Add single comment keeps today's Publish exactly.
