The rule all four keep

A post's mark goes in the same place whether the post is the root or a reply, and whether the thread has one post or many. The card header now holds only the line (or tour stop) and the state pill. The mark is shown without its word, with the tint, tooltip and accessible name accepted in round v2 ("issue (blocking)"). A plain post shows no mark.
