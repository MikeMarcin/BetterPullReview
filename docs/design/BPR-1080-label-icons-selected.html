How to draw them

  • Grid and pen. Coordinates are on a 24-unit grid. The glyph fills a 12 px box centred in the 16 px mark, so one unit is 0.5 px at 1×. Strokes use round caps and joins and a 2.6-unit pen unless the element names its own width: typo's squiggle is 2.0 and chore's handle is 2.2.
  • Element kinds. stroke strokes the path. fill fills it with no pen. disc fills a circle. The paths use only M, L, C and Z, which map one-to-one onto QPainterPath moveTo, lineTo, cubicTo and closeSubpath. A disc is addEllipse, and a fill is QPainter::fillPath.
  • Holes. The holes in typo's A and b wind against their outlines, so the nonzero and odd-even fill rules give the same result.
  • Colour. The soft mark draws the glyph in ink on a 22% (light) or 30% (dark) tint fill with a 1.5 px tint border. The blocking mark fills with the full tint and draws the glyph in white or #111418, whichever contrasts more. Tints are BPR-1079's built-in table and are configurable on Appearance › Colours.
  • Names. Each mark is an image named by its label, with "(blocking)" when it is blocking. The tooltip uses the same words. The Label key lists every name with its shortcode. The shape carries the label and the tint only adds to it.
  • Resource form. The data compiles into the Qt adapter. There are no SVG files, no Qt SVG module, no icon font, no runtime fetch and no generated image.
  • Provenance. The rfc-implementer agent (Claude Opus 5.5) wrote every coordinate by hand for BPR-1080. The owner's three reference images (broom, small wobble, Abc) set the style for chore, quibble and typo. Nothing was traced, and no icon set or image generation was used. The data belongs to the repository.
