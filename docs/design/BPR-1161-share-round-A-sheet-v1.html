Direction A: a share sheet over the code

BPR-1161, share-round design round v1, for RC61-05. Drawn on 2026-10-02 from the rejected candidate BPR-1161-compose-share-v001 (built at 7a385389c).

Sharing becomes a short, window-attached sheet that drops from the review bar and leaves the code visible behind it. It asks two things, shows what goes out, and offers one obvious button. When you are done it closes and you are back where you were.

The owner’s three complaints, answered

“There is a lot going on in this screen and it’s not a very pretty experience. I have no idea how I got to this screen, why I would wnat to do any of these actions, and what is important.”

How did I get here?
The review bar’s unlabeled pencil becomes a labelled Share notes button that carries the number of notes waiting. The sheet hangs from that button’s row, over the file you were reading, so the code you came from stays visible behind it. Its title, “Share round 2”, and its first sentence say what a round is: the notes you have written since you last shared.
Why would I do each thing?
Every choice states its purpose where it sits. Each of Discuss, Plan and Implement has one line saying what it asks the recipient to do. Copy and Save each sit beside a sentence saying when to use them. The bundle and the exact text are links in the sheet’s foot, each with its own tooltip.
What’s important?
One filled button, Copy round 2, the default (Return). Save is the second, equally visible but quieter. Everything else is either a fact the reviewer needs (which notes are going) or a link. Hashes, byte counts and the digest move to the exact-text view.

What changes from the rejected page

  • No page replaces the code. The file list and the Notes tray stay where they were, dimmed, so nothing appears twice beside the share controls.
  • The always-visible preview pane goes. Read the exact text opens it as a document tab: the same bytes, with the digest at its foot.
  • Move Up and Move Down go. Notes are reordered by dragging the grip, or with Option+Up and Option+Down on the focused row.
  • “Shared so far” appears only after something has been shared, together with what to do next.
  • “Feedback round F2 · frozen” becomes “Round 2 is now fixed as you shared it”. F2 stays the round’s name in the exact text and in bpr cycle.

Building it in Qt

A QDialog opened with Qt::Sheet on macOS, where AppKit attaches it to the window, and window-modal and centred under the review bar on Windows and Linux. Everything in it already exists as a widget: a segmented control (three checkable QToolButtons), a line edit, a list with drag reordering, and two push buttons, one of them the default. No window chrome changes, which RC61-02 asks for. Escape, or Cancel, closes the sheet and changes nothing.

What it costs

  • A modal sheet hides the code while it is open. Checking a note against the source means closing the sheet, which keeps the draft.
  • Long rounds, from about eight notes, make the list scroll inside the sheet. It stays compact by design, so a reviewer who edits a lot of notes before sharing does that in the Notes tray.
  • The exact text is one click further away than it is today.
