The agent footer on the pull request window

The picker leaves the Agent tab's composer, the Tour tab's bar and the Enhance popups. One place at the bottom of the window says which agent this pull request uses, what it is doing wherever it was started, what the session has cost, and stops it.

1 · In the status bar
The bar that is already there gets two halves: the review on the left, the agent on the right, under the drawer where its conversations are. No height is added. The review's message is the part that shortens when the window is narrow, and the grant line of RFC-BPR-0104 has to live in the picker's menu.
2 · Its own bar
A 31-point bar above the status bar, which stays as it ships. There is room for the grant line in words, for the agent's name in the status and for last activity. It costs a line and a half of code on every pull request, and is mostly empty while nothing runs.
