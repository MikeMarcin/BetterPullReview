Prompts in Settings: surfaces, and a prompt library

Mockups for BPR-2179, round 3, after the owner split the section in two. Surfaces say where prompts appear: the pull request, file and thread Ask menus, and each one’s suggested chips. The prompt library is where prompts are made and edited, conditions included. A prompt is put on a surface by dragging it there or by right-clicking it.

The worked example is “Was this addressed?”: on the thread menu, the thread chips and the pull request menu, with its conditions on the prompt. Each direction is drawn for all repositories and as acme/checkout-api changes it. The prompts, conditions and repository are invented.

The same in every direction

Six rules do not depend on the layout, so they are drawn once.

Direction 1: Three panes

One page. Surfaces down the left, the library in the middle, the selected prompt’s editor at the right.

How the two parts sit
Everything is on screen at once: all six surfaces, every prompt, and one prompt open.
Adding and seeing where a prompt is
Drag a prompt left onto a surface. Each library row says its surfaces in words, and selecting a prompt outlines its placements in the surfaces pane.
What it gives up
The editor is the narrowest of the three directions, and the six surfaces share one column, so a long surface makes the pane scroll.

Direction 2: Two pages

Two entries in the Settings sidebar. Prompt surfaces is the three scopes side by side with a shelf of the library under them to drag from. Prompt library is the list and a large editor.

How the two parts sit
Each part has a page to itself. The surfaces page carries a shelf of the library so that dragging still works; editing happens on the library page.
Adding and seeing where a prompt is
Drag a prompt up from the shelf. On the library page each row has a mark per surface in three columns, and the editor lists the prompt’s surfaces with Show.
What it gives up
Ordering and editing are a page apart: from a placement to its text is a jump, and the shelf repeats the library.

Direction 3: Source list

One page with its own short list at the left, as Music has a library and playlists: All prompts, then the six surfaces. The library view is the list and the editor; a surface opens as its ordered list with a preview.

How the two parts sit
One thing at a time, chosen at the left: the library, or one surface.
Adding and seeing where a prompt is
Drag a prompt onto a surface’s name. Each library row says its surfaces in words, and the counts at the left say how full each surface is.
What it gives up
The surfaces are never all visible together, and a drop lands at the end of a surface: its position is set after opening it.
