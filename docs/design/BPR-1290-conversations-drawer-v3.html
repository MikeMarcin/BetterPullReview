The map

The Conversation tab opens on a map of every conversation in the pull request, grouped by file. Pick a conversation, or any post in it, and the reader shows the branch from the first comment to that post, then what follows it.

A rowOne conversation: its line, who started it and its label mark, then one node per reply, oldest first. On the right: new count, ✓ resolved, or a lock for your draft. A line, not a treeReplies sit on one line in the order they were posted. A reply that has replies of its own starts a lane underneath, joined to the post it answers. A GitHub thread, where every reply answers the first comment, is one line, so the map branches only where the conversation does. A long lineFolds its oldest read posts into a count. The picked post and new ones never fold. A nodeThe post's label mark (BPR-1083), or the author's initial when it has no label. A blue ring means new. Read posts are faded. PickedAn amber ring, and an amber edge on the same post in the reader. The path from the first comment is drawn heavy and what follows is drawn light. The reader shows only that branch; ⑂ n marks where other branches leave it. ToolbarThis file or whole pull request; only new (●); only unresolved (○); highlight a label, which fades everything else in place rather than hiding it.
