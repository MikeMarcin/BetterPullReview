The Windows title row with five modes

Every strip on this page was drawn by Windows: the application's own title row, built from the lane's sources on the Windows station with Qt 6.12, laid out by the rules the window uses and read back without showing a window. Under each strip is where its width went, to the same scale.

Mockups for the owner to choose from. No product code changed. The pull request, its branch and its title are invented.

Windows draws the row in Segoe UI at 9 points, 12 pixels at 100%. That is the system's message font, which Qt hands the application as its general font; nothing in the application picks a face. The crunch is not the face. On macOS a mode's key is two glyphs, ⌘1. On Windows it is six, Ctrl+1, and five of them are as wide as a short title.

Faces Windows ships, on the same five modes

Each line is a label drawn by Windows in that face. The number is the five names with their keys, as the switcher sets them, without the padding.

Segoe UI Variable is the Windows 11 face and is absent on Windows 10. Its Small cut is wider than Segoe UI by design; its Text cut is within three pixels of it. Bahnschrift is on Windows 10 and 11 and is the only shipped face with a narrow width.

The options

Each is shown at 1280, 1366 and 1600 logical pixels wide on a pull request the viewer owns, in Revise, with the branch chip the accepted Revise design adds. The title is long on purpose.

Recommendation

B, keys in tooltips. It is the only option that answers the crunch at every width without a new visual language. The names stay whole, the face stays the system's, and the title gets back the 195 pixels the hints took. The keys are already in each mode's tooltip and in Keyboard Shortcuts, and the row already drops them below 1300 today.

It also removes a rule that works against the title. Today the title shows only if it would also fit beside the switcher with its keys, so that it does not come and go as the keys do. With five modes that rule refuses the title at 1280 while a fifth of the row sits empty. With no keyed form there is nothing for the title to wait on.

A is the honest answer to the question as asked, and it is not enough: the best face gives back 42 pixels and changes the row's voice. If the Windows 11 face is wanted for its look, Segoe UI Variable Text can be adopted with B at no cost in width; that is a separate choice.

How these were made

A scratch program in harness/ compiles the lane's workbench_strip.cpp, windows_caption_buttons.cpp, keyboard_shortcuts.cpp and three small dependencies as they are, so the strip, its button style, its glyphs, the four-mode switcher and the caption buttons are the application's. The fifth mode, the branch chip and the options are drawn in the program on that same style; its switcher measures the same as the application's at four modes in all three forms. It ran on the station over SSH with Qt's Windows platform plugin, every widget marked not to show on screen and read with QWidget::grab(), once each at scale factors 1, 1.25 and 1.5.
