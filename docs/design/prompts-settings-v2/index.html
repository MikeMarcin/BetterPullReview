Prompts in Settings: three ways to show one prompt in several places

Mockups for BPR-2179, round 2. Each direction is the whole Prompts section, drawn twice: with “Was this addressed?” open for all repositories, then as acme/checkout-api changes it. “Was this addressed?” is in the thread Ask menu and is a thread chip when there are new replies or pushes since the comment; it is also in the pull request Ask menu, where one ask covers every open thread.

All three keep the filter, a large edit area, drag to reorder, and placement visible in the list. The prompts, conditions and repository are invented.

Direction 1: Grid

One row per prompt. The three scopes are fixed columns, each with a mark for the Ask menu and a mark for the chip, so a column reads top to bottom as “everything on a thread”. The editor repeats the same grid at full size.

One prompt, several places
A prompt is one row; its places are marks along it. The editor has one line per scope with two boxes, and the chip’s conditions under the line.
A repository’s changes
A “Prompts for” pop-up switches the whole section to a repository. Whatever differs there is ringed in teal, in the list and in the editor, and each has its own Use app-wide.
What it gives up
The marks need learning (a small legend carries them). Conditions are not visible in the list; they are in the editor.

Direction 2: Sentences

One row per prompt, and its places are written out: “Pull request menu, Thread menu and chip”. A row opens in place into a wide editor, where each scope is a ticked line with its places and the chip’s conditions beneath. Repositories are tabs on the prompt.

One prompt, several places
A prompt is one row; its places are words, so nothing needs a legend. Open, each scope is a short paragraph of ticks, read top to bottom.
A repository’s changes
Each prompt has an App-wide tab and one per repository that changes it. On a repository’s tab the changed text is highlighted and the changed tick is ringed, each with Use app-wide. Rows name the repositories that differ.
What it gives up
No view of a whole repository’s list, so a repository cannot have its own order. Words are slower to scan down than a column of marks, and the open row pushes the rest of the list down.

Direction 3: Surfaces

The three Ask menus and their chips drawn as they show, side by side. A prompt appears once in every place it shows; picking one fills it and outlines the others, and the editor below has a tab per scope.

One prompt, several places
A prompt appears in each list it is in. Selecting any of them outlines the rest, with a link mark. Dragging a prompt onto another list shows it there too.
A repository’s changes
A “Prompts for” pop-up shows the lists as the repository will see them, with what differs tagged in place: Added here, Off here, Only here. The editor names each difference with its own revert.
What it gives up
There is no single list of prompts: a prompt that shows nowhere, or is off, needs a shelf (not drawn). Each of the six lists has its own order, which is more than the one order settled in the grill round.
