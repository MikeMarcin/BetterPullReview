Arriving at a stop

Choosing stop 1, by its row, a key, Next, or a link, opens its file and reveals its lines. There is no Show in code. The stop's file-and-lines line is a link that brings the lines back if you scroll the code away.

When a stop needs accepting

The ring turns yellow and the stop says why in one line, with Accept beside it. Accept does not move you to another stop. The ring itself still only opens and closes the stop.
