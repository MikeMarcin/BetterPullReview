# PACK-DIF-10: Wire accepted resources and Dif into current Home

## Outcome

Bind resources through app/Qt composition and inject one shared cache to workbench windows. Integrate Home slot and actual Settings without altering the current PR-open/retained-review behavior.

## Acceptance

- Normal app visibly greets once, breathes, blinks at cadence and rests under real settings.
- Home covering a retained review works; return preserves selection/scroll/epoch/focus.
- Compact layout hides art before controls; only accepted generated outputs are linked.

## Evidence

Record focused command/gesture, direct surface, result, producing revision, and remaining limitation. Evidence is **not run** at pack authoring. Reuse still-valid prior results; never infer a native/art verdict from a fixture.

## Boundaries

No GitHub/GHES mutation, model run, credential access or shared-skill replacement is authorized by this card. Any required creative edit remains offline and separately recorded; ordinary builds and the product perform no image generation. Follow the milestone exit rather than running an exhaustive app-wide course for this slice.
