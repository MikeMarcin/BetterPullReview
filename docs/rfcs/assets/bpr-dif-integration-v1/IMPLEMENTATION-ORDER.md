reusing unchanged evidence. Shared attended-review only for the explicit asset and
real-app visual questions, with partial responses preserved. Platform work uses the
live lanes, and missing target evidence is recorded rather than replaying every UI case
on every device. Use live configured routine/deep/reviewer roles; no model names, effort
levels or fleet paths are hardcoded into this pack.

clips must be distinct, approved and reachable in ordinary app flows. Technical delivery
and formal canonical RFC closeout remain distinct; never close unrelated predecessors
or falsify an Auto-Verified status to unblock a document.
