# Review preparation defaults

These are proposed **BPR application writing-hook resources**, not coding-agent roles and not installed or executed by importing the RFC pack. The app loads the selected text through its existing profile/settings system once implemented. Four user-customizable hook texts share a noncustomizable application contract in `application-contract.md`.

Use the installed `implement-rfc` skill to implement the feature. Do not install these as a new autonomous orchestration skill, run them on launch, or grant them GitHub mutation tools. A selection scope is passed to the appropriate writing hook; it is not a fifth skill.

The request/result examples in `../examples/` and schemas in `../specs/` are offline contract fixtures. Actual agent delivery must use the existing BPR transport/profile boundary. Results are delivered into a captured local editor transaction; there is no required Accept/Apply/Dismiss panel.
