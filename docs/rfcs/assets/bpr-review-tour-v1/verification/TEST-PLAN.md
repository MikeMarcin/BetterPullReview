# Verification plan

Use the existing project's network-isolated/default-deny test infrastructure. Existing production provider/session, real admitted SQLite, native editor and real application composition are the subjects. A static marker, generated screenshot, pure reference splice or canned fake server alone cannot prove the whole feature.

## Layers and evidence classes

| Layer | Direct subject | What it cannot prove alone |
|---|---|---|
| Core | Identities, field generations, stop ordering, exact range policy, readiness, edit splice authorization. | Qt undo/selection, network effects or website behavior. |
| Markdown codec | Source spans, ordinary links, root/list parsing, byte preservation, fallbacks and bounds. | Full GitHub rendering or permissive mutation authority. |
| Provider contract | Exact methods, documented payloads, raw body/ID normalization, paging and errors. | Deployed service support or private-host policy. |
| Recovery | Real journal transactions, independent fake service state, process death and ambiguous replies. | General exactly-once networking or power-loss durability beyond observed tests. |
| Application | Real command/effect/projection paths, finite parent/child authority, cancellation and profile/window identity. | Native usability or real remote account attribution. |
| Qt | Native editing, selection, IME, undo blocks, keyboard/reorder, safe preview and display scales. | Model factual correctness or publication success. |
| Designated service/website | Pending membership, real URLs, author identity, single-review submission, normal replies, maintenance and cold reimport. | Untested GHES versions, transports, platforms or account policies. |
| AI quality samples | Focused problem/solution/stop examples judged against supplied facts. | Guaranteed correctness on arbitrary changes, comprehension or reviewer attention. |

## Required negative families

**Identity and permissions:** wrong server/repository/PR, same number on another repo, actor change, deleted root, third-party linked comments, draft-generation replacement, opaque/numeric ID confusion, high uint64 identifiers, recovery after local state loss. An observed URL is not authority for a write.

**Publication ambiguity:** kill before persistence, after persistence but before witness, after witness before response, after server acceptance before receipt, after some navigation patches, and after submission before local reconciliation. Simulate delayed visibility, partial pages, multiple exact-looking candidates and another client adding/submitting/deleting pending content. No automatic resend, fallback or rollback from an unknown outcome. Reconcile a known old-head attempt without inventing a new write at the current head.

**Update conflicts:** description/body/index/footer edited on website, B/L/R divergence, section offsets displaced by new headings, read/write race without CAS, partial insertion and reorder, two BPR windows, removed tour membership with existing replies and immutable native anchor retargeting. Preserve the actual remote objects and all conflicting local text.

**Editor scope:** no selection, caret only, whitespace-only selection, whitespace-only field, selected phrase inside emphasis, selected Markdown delimiter, multiline CRLF, tabs, emoji, surrogate boundaries, combining marks, mixed line endings, IME composition, native undo after adjacent typing, redo with no model call, equal output, toolbar focus transfer, moved caret, closed/suspended editor and simultaneous result/keystroke ordering. One authoritative document generation invalidates all stale results, even after undo returns to identical bytes.

**AI scope:** malicious instructions in source/PR/body/link text, extra result fields, source references outside supplied context, output that supplies new target/range/Ready flags or publication actions, full comment bodies in outline, oversized/invalid UTF-8, no evidence for a why, model failure/cancellation and response arriving after stop navigation. Verify no inference on manual activity and no Jira/issue fetch. Skill settings cannot bypass any application rule.

**Markdown and links:** fenced fake headings, quoted footers, nested or repeated indexes, unresolved/deleted targets, cross-PR links, escaped title delimiters, credentials in URLs, non-HTTP schemes, raw HTML/image resources, deep nesting, huge single lines and parser work budgets. Preserve source; unsupported rendering is explicit, not dropped or executed.

## Manual-first end-to-end fixture

Card 16 must prove the entire user journey without an agent profile using the real app composition and a typed fake service plus real private storage. The fixture service independently counts creates, edits, submits and status effects. Exercise later website-style edits and restart/cold import. This lets later optional AI engineering proceed without requiring a company production PR as a test target. Live host and usability qualification remain separate requirements.

## Scale and responsiveness

Measure 1, 12, 100 and 256 stops; short and maximum-admitted bodies; many related source links; long raw PR templates; paged server comments and existing large-review source fixtures. Record target/platform, build, input bytes/counts, peak retained content and UI event/operation latency. Compare with existing BPR budgets and define a justified feature threshold during implementation. No fixed unmeasured “fast” result is supplied by this pack.

Check that reordering does not reload every source file, applying a field edit does not rebuild the whole workbench, unchanged projection acknowledgements do not reset text/undo, and native preview refuses excessive input before expensive layout. Effective smaller inherited transport/editor limits remain real until deliberately changed and measured.

## Final evidence

Every matrix row names producing revision, exact command/course, actual outcome, evidence class, and remaining limitations. Screenshots show layout only unless a interaction walk also ran. Captured API shapes are not subjective website acceptance. All unobserved platforms or capabilities remain Not run/unavailable rather than inheriting another host's pass. Keep ordinary review, source-line publication, privacy and auth regression checks in the final focused pass.
