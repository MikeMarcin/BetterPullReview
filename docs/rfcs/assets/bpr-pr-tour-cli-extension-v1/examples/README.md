# Synthetic contract examples

All objects are offline fixtures, not recordings. The `.test` host, repositories, IDs, and operations are invented. The integers represented as decimal strings deliberately exceed JavaScript's exact integer range. Do not send these objects to a real service or interpret a result fixture as an approval.

The CLI envelope examples exercise complete/partial recovery, stale edits, explicit interaction and uncertain publication. The assistance result intentionally uses the predecessor's `bpr.review-preparation.result.v1` shape rather than introducing another output language. The actual context ticket/range stays host-owned, outside model output.

[scenario-catalog.json](scenario-catalog.json) enumerates required runtime/attended courses; all start Not run. [text-ranges.json](text-ranges.json) provides exact byte-range and generation reference cases for the offline pack checks. Passing those reference checks does not prove a Qt editor, owner channel, native CLI, model, or GitHub operation works.
