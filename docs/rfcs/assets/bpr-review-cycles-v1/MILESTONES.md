## Execution discipline

Use the installed skill's current worker/reviewer choices and selected topology. This pack specifies engineering outcomes, not model routes, integrator lifetimes or a new supervisor. Routine focused work should remain routine; use critical scrutiny for authority, bytes/anchors, storage recovery and publication. Do not create a new global acceptance wizard per card. User/host qualification gates remain explicit where actually required.
