# Candidate skill distribution

The candidate `bpr-cycle` teaches an existing harness to consume a specific prepared
Review Cycle through the provider-neutral CLI. It does not implement review storage,
publication, authorization, orchestration or a second model session.

Install only after the CLI exists and its syntax/capabilities are verified. Use the
canonical shared AgentSkills repository and established MASK distribution workflow;
record source revision, deployed content digest and consumer compatibility. Do not
create divergent hand-maintained BPR-local Claude/Codex copies. This archive does not
install or authorize installing the skill, and missing upstream permission remains a
stated distribution gate. Ordinary Markdown/CLI instructions work without native skill
support. Any harness must still allow the relevant local commands and data disclosure.
