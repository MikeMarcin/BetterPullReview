boundaries intentionally join the actual design and shared service work. Within
each milestone respect explicit card dependencies; do not dispatch a new worker
for each tiny checklist item. Use the installed execution topology and routing,
not model names or orchestration rules copied from an archive.

local verification continue. Never mark that milestone/closeout complete by
substituting fixture evidence for required website observations. Existing formal
canonical closeout remains distinct from technical work; this plan does not waive
predecessor gates or force the implementation of unrelated deferred RFCs.

Adapt the stored schema representation to the installed importer if necessary,
