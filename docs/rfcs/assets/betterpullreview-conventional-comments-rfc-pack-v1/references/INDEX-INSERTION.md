# Additive index insertion

After checking/remapping all five new IDs, append their rows to the current live
RFC index in canonical order. Preserve every predecessor entry, status and
historical link. Use the live filenames and dependencies from the remapped RFC
frontmatter; all five begin Proposed. Do not copy an old index over the live one.

A proposal's registration is not implementation acceptance. Technical progress and
formal closeout use the existing per-criterion ledger and canonical ordering.
