# Issue Plan for RFC-BPR-0019

## Goal and authority

Create an original, provenance-complete Dif source pack and deterministic
sprite catalog without adding a runtime mascot. The product owner's 2026-08-12
request to design and then implement the Dif RFCs is the explicit post-pack
implementation-frontier advance. It does not assert ownership of the supplied
references, approve derivative or distribution rights, provide a visual
verdict, or waive ordered RFC closeout.

Production art remains blocked on BPR-0287. Offline contract tooling may land
first because it consumes no supplied artwork and grants no asset rights.
RFC-BPR-0020 cannot begin unless RFC-BPR-0019 becomes Auto-Verified.

## Architecture allocation

| Boundary | Responsibility | Explicit exclusion |
|---|---|---|
| Qt adapter asset root | Owned neutral master, source frames, manifest, provenance, generated strips, generated fixed descriptor | No widget, timer, setting, runtime JSON parser, network source, or application composition |
| Offline maintainer tooling | Strict PNG/schema validation, deterministic resize and strip/catalog generation, previews, clean-tree comparison | No model call, network request, nondeterministic metadata, or ordinary build dependency |
| Tests | Hostile manifest/PNG cases, byte-for-byte regeneration, geometry/alpha/limit checks, build-graph isolation | No static contact sheet substituted for motion or human identity judgment |
| Attended review | Exact rights decision and exact identity/motion/scale/appearance/rest verdicts bound to content digests | No inferred legal truth, reused stale verdict, or approval of unreviewed bytes |
| Core, application host, composition | No impact in this RFC | No mascot type, asset, timing, preference, or effect crosses inward |

## Required verification families

- Python-standard-library contract tests for PNG structure, ancillary-chunk
  policy, RGBA/alpha, dimensions, gutters, edge clearance, body bounds,
  baseline, travel, timing, returns, totals, paths, digests, and unlisted files.
- Two fresh empty-directory regenerations compared to one another and the
  committed generated tree byte for byte.
- Compile validation of the generated descriptor without a runtime JSON parser.
- Mechanical seam and greet-to-idle handoff analysis plus digest-bound animated
  previews at shipping sizes and declared speed.
- Developer, core-only, and tests-disabled application graphs proving the
  generator and art toolchain are absent and no Dif asset enters the core.
- Scoped metadata/private-path/credential/foreign-identity scans of the Dif
  pack and its evidence, without rejecting legitimate RFC prose.
- Local or target-native execution only; GitHub Actions is never evidence.
