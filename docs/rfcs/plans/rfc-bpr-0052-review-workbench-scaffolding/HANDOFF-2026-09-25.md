## Working rules that proved necessary

- Stations and Mac agents share `origin/main`: `git pull --rebase` before every push,
  explicit-path commits, docs gate before push, reseal and review composition pins
  whenever pinned sources change (two red-main incidents came from skipping this).
- One ID allocator at a time: pull, `scripts/allocate_issue_id.py`, push at once,
  titles in the commit message.
- If another writer has uncommitted work in the primary checkout, work in a
  scratch worktree off `origin/main` instead of stashing theirs.
- On macOS, ctest's network-isolation runner replaces `TMPDIR`; leftover checks need
  a direct sandboxed run.
