## Compatibility correction and discrimination

The baseline has no namespace/member roles or blob-local declaration facts.
M1 adds those stable identities and bounded C++ refinement without renumbering
old roles or changing any existing default color. M2 found that host admission
measured an omitted additive field's unassigned sentinel as actual black ink.
It now defers that sentinel to presentation's existing built-in default path.
Explicitly supplied colors retain contrast admission, including the new
namespace negative control. No parser, storage-schema or contrast floor changed.

Theme admission retains its existing all-variant contrast check. A standard
built-in palette is qualified for its own variant and need not satisfy every
high-contrast import floor. The exchange fixtures are valid customized themes
under that existing policy, including current-line/selection washes; their old
comment/function values remain distinguishable and are preserved exactly.

The raster assertion initially failed with the three drawers open: token
formats existed but qualified names were clipped. Closing drawers through the
public actions made the names visible and the pixel checks passed. The restart
course waits for the asynchronous durable load before judging settings. These
failures establish why formats and startup completion alone are insufficient.

## Scope and limits

Evidence is macOS arm64, Qt 6.11.2, scale 1, offscreen and network-denied synthetic
fixtures. The frontend-design skill was loaded for visual qualification.
No installed/release, native desktop, human or independent verdict is implied
or required by this RFC. Blob-local recognition remains best effort; includes,
external symbol resolution and alias-target propagation are outside scope.
Historical BPR-0720/BPR-0738 verdicts and obligations remain intact.

The broad `qt_appearance_profile` row failed its existing font-resize assertion:
"the reprojected position keeps its comparison and visible reading line within
one row." This occurred before M2's host correction; that test, Qt runtime and
palette inputs are unchanged by this milestone. Its cause remains unadjudicated
and its failure is retained, not counted as a passing suite. It does not replace
or invalidate the direct RFC category, contrast and persistence checks. No
scrolling work was authorized or performed here.
