## Incremental durable read presentation

The failure was not resolved by waiting before checking a retired widget.
A controlled public course holds the actual ledger-effect lane, opens a New
inline thread and its reply's actual context menu, and releases persistence
while the menu is active. The old product destroys the card, body and menu;
the initial controlled negative failed in 3.19 seconds.

The repair changes Qt presentation only. Read-state-only updates adjust the
header count, read action, post dots and New divider within the existing card.
Readers, context actions and the unsent reply keep their identities. Moving
the divider preserves the first visible post's position. Actual body and
structural changes still use the existing card replacement path. Core policy,
provider effects, persistence, schemas and dependencies are unchanged.

Three final regressions cover the active menu's exact Open in Review route and
reply/anchor, immediate Reply text and caret through the real held durable lane,
and the same reader/viewport while a mixed-read New divider moves and disappears.
All three fail with only the four production presentation files substituted
from the rejected source (6.12 seconds total). Restored file hashes match the
tested repair; all three then pass in 8.74 seconds. No assertion, timeout or
containment rule is weakened.

All nine focused rows at 100%, 125% and 200% pass. The seven-row composed
integration passes in 54.47 seconds, including composed GitHub at all three
scales and the existing navigation course on macOS. Strict clang-format 22 and
clang-tidy 22 cover the touched surfaces. Offscreen menu and full-application
renders were inspected; this is content/layout evidence, not native appearance
or physical-input qualification. The frontend-design skill was loaded; the
existing palette, typography and layout are retained.

Raw commands, failed/positive JUnit, source hashes and renders remain in the
external release session. Final signed artifacts, native trust, current
security/material decisions and publication evidence are still pending.
