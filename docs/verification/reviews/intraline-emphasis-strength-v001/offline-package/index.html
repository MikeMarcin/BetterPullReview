Reference: Pick one. These are five alternatives to a single question - how strongly the changed characters inside a diff row should be marked - not five independent pass/fail checks. Choosing one records the others as not chosen, never as defective. The trade is fixed and unavoidable: the added span can travel a long way from its row fill at almost no cost because green carries 0.7152 of relative luminance, while the removed span cannot, because red carries 0.2126. Making red visible means making it darker, and darker spends the contrast budget of the code sitting on it. Every candidate below is one point on that trade. Captures are offscreen QFusionStyle at device pixel ratio 1; native artwork, issue closure, RFC closeout, and release readiness are all outside this batch.
