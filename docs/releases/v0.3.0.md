# BetterPullReview 0.3.0

Coordinated private stable release for macOS universal, Windows x64 and Ubuntu
26.04 x86_64. Full agent integrations and local automation are included.

## Changes since 0.2.2

- Review drawers share a consistent layout. Overview has a remembered Status
  drawer that leads with your role and what needs attention. Compose review
  opens beside the code and expands into a focused page; Tours presents the
  route, Notes supports private line anchors, and Agent has its own drawer tab.
- Pull-request comments have read state and appear at the Comments drawer's
  edge. Quoted replies retain their original target, long threads remain
  readable to the last post, and a selected thread can open in Threads or Discuss.
- Markdown descriptions and comments show inline images, including SVG and
  WebP, with a bounded profile cache and a preference to disable loading.
  Rendering also supports GitHub-style alerts, footnotes, disclosures, emoji,
  language-coloured code fences, diff blocks and suggested changes.
- Whole PR compares from GitHub's evidenced merge base, including supported
  stacked pull requests. The Updates line starts at that base, and recorded
  updates can supply comparison handles again. Refresh preserves valid
  base-line drafts and the review mode chosen while loading.
- New Insights shows local storage, passive GitHub request and rate-budget
  history, review activity, energy measurements and work timings. Unavailable
  child-process CPU counters say Not reported; they are not estimated.
- Text selections and intraline changes are clearer, C++ template syntax is
  coloured, and both comparison panes receive highlighting. Folder counts
  appear only while collapsed, and Home, refresh and data-readiness feedback
  make the current state easier to follow.
- Accept file uses Option-A on macOS and Alt+A elsewhere. Home uses
  Command-Shift-H or Ctrl+Shift+H; Actual Size uses Command-0 or Ctrl+0.
  First/last-change shortcuts and Help's Keyboard Shortcuts reference are
  available, and macOS Option-letter keys work normally in text inputs.
- Review submission recovery handles busy pull requests and explains an
  unconfirmed result. File/change navigation works after opening another pull
  request, GitHub CLI discovery failures provide safe diagnostics, and Settings
  groups controls by task with scoped Troubleshooting resets.

## Verification and distribution

All selected producers use one committed version and source revision. Native
normal-gate results, configured skips, final package identities, digests and
trust observations are recorded in the release engineering and producer
records; focused or historical checks do not establish a new full native pass.

macOS targets macOS 13 or newer on Apple Silicon and Intel, with Developer ID
signing and notarization. Windows supplies a per-user MSI and runtime inventory
archive; that archive is not a qualified portable installation. Ubuntu 26.04
supplies a DEB and per-user archive, with declared system dependencies and the
glibc 2.43 ceiling. WSL2 is an admitted Linux producer.

Each platform supplies SPDX, checksums and a separate exact-version
corresponding-source archive. Equivalent source access at no extra charge,
practical build/relink material and immutable retention remain ongoing
distribution obligations, including corporate and offline redistribution.

## Known limitations

This release does not complete RFC-BPR-0038 native or release-security
qualification. Clean-account installation, authentication and platform vaults,
native Intel and complete Windows/Ubuntu desktop courses, accessibility,
upgrade/removal, resident-material crash privacy and vulnerability qualification
remain open. Historical licensing/security decisions apply only to their exact
artifacts. Qt 6.11.2 findings still require exact-version applicability
dispositions; signing and notarization do not resolve dependency findings.
WSL/WSLg observations do not establish clean Ubuntu desktop or Secret Service
qualification. Profile purge excludes shared updater and registry state and is
not uninstall.

The release remains private. Version 0.3.0 is selected as a stable GitHub
release, eligible for Latest, rather than a prerelease.
