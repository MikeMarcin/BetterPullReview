# BetterPullReview 0.1.3

Private macOS patch release for account setup and GitHub Enterprise PR links.

## Included

- Home and pasted PR links share a focused sign-in dialog. Settings retains
  connection management, without repeated setup and continuation buttons.
- Use GitHub CLI starts account discovery immediately. A sole matching account
  advances to the trust confirmation; multiple accounts offer a named choice.
- Pasted PR links reuse the accepted CLI session for that exact server, even
  when an unconnected native account option also exists.
- A pending PR resumes after sign-in. Canceling or replacing setup ignores late
  discovery results and preserves the current review.
- GitHub CLI discovery now requires `gh` 2.96 or newer for token-hidden JSON
  account discovery. This replaces the 2.45 compatibility path in 0.1.2.

## Known limitations

- Home does not yet automatically discover authored or requested PRs. Paste a
  PR link to open it.
- GitHub CLI discovery uses the default configuration for the macOS user;
  custom `GH_CONFIG_DIR` overrides are not imported.
- Full Git comparison remains qualified for `gh` 2.100.0 with Apple Git 2.50.1.
- Live reply submission and reconciliation remain under repair in BPR-0896.
