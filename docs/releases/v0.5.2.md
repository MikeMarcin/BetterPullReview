## Changes since [0.5.1](https://github.com/MikeMarcin/BetterPullReview/releases/tag/0.5.1)

### Fixed

- Large pull requests stay more responsive while opening. You can select a reported file while the comparison is still loading.
- Fixed an intermittent stall when Git or GitHub command workers shut down.
- The Commits tab loads its file counts when opened while a pull request is still loading.
- Tour stops retry their comparison when a push lands during a background read.
