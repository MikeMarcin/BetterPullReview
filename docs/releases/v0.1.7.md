# BetterPullReview 0.1.7

Private macOS prerelease for early testing on macOS 13 or newer, with native
Apple Silicon and Intel binaries in one universal application.

## Included

This patch release includes the 0.1.6 functionality and these Home corrections:

- Retained pull requests refresh their titles and review facts on Home.
- Home keeps its layout stable as its content updates.
- The Home tooltip shows its keyboard shortcut.
- Release assets list the application builds before the corresponding source.

## Package and verification

The owner requested a full development test run on 2026-10-10 and explicitly
allowed publication despite test failures. Tests run separately from packaging;
their results are reported with the release handover and are not a release gate.
The packaging command uses `--skip-tests` to avoid a second blocking test run.
The previous 0.1.6 large-history responsiveness timing failure remains an
unresolved observation unless this version's test evidence establishes otherwise.

The release workflow produces a tests-disabled universal application. Packaging
checks the restricted Qt runtime, both architecture slices and macOS deployment
floor, installed notices, and a relocated launch. The app and DMG require
Developer ID signing, Apple notarization and stapling, and Gatekeeper assessment
before publication.

The release includes a DMG, app ZIP, SPDX inventory, and a separate exact-version
corresponding-source ZIP, each with its own SHA-256 file. Keep source access
alongside binary access; redistribution must preserve the source offer and
the exact corresponding-source asset.

## Known limitations

This prerelease does not complete RFC-BPR-0038 release qualification. M8/M9
clean-account vault, native Intel/platform, crash privacy, and vulnerability
qualification gaps remain open. The recorded Qt 6.11.2 vulnerability scans
have unresolved findings; signing and notarization do not resolve them.

An intermittent file-selection race remains tracked for investigation in this
prerelease. Tour publication remains dependent on exact host and transport
qualification. Installed agents and GitHub CLI are separately configured
capabilities. Profile purge excludes shared updater and registry state and
is not uninstall.

This release remains private and is marked as a GitHub prerelease; it does
not replace the current stable Latest release.
