# BetterPullReview 0.1.9

Private macOS-only prerelease targeting macOS 13 or newer, universal Apple
Silicon and Intel. The owner narrowed this release to the current Mac build
on 2026-10-12; Windows and Ubuntu 26.04 packages and remaining repairs are
deferred to a follow-up patch. No follow-up version is selected here.

## Included

This patch includes the 0.1.8 functionality and these improvements:

- Home separates authored pull requests from reviews needing your attention.
- Draft pull requests show their draft state on Home and in recent history.
- Overview shows check results, merge blockers, and named pending reviewers.
- Home explains review waiting and concurrent blockers, preserving accepted
  observations across refreshes and restarts and identifying partial summaries.
- The release test gate runs independent tests concurrently and reports timings,
  while keeping Qt and end-to-end courses serial.

## Package and verification

Distribution builds disable tests and retain the full agent and local automation
capabilities. The normal Mac test gate and focused repair checks retain their
actual failures and configured skips. The owner explicitly accepts the current
Mac timing misses for v0.1.9. Responsiveness and launch exceeded the unchanged
100 ms PR-load input-gap budget, including isolated misses at 104.4 and
101.1 ms; these are failed observations, not passing timings. The Debug
cache-bytes course is a configured skip and supplies no optimized-course evidence.

macOS requires Developer ID signing, notarization, stapling and Gatekeeper
assessment for its universal app and DMG. Runtime audits, source binding and
downloaded artifact verification remain required before claiming release
completion.

The selected set supplies the macOS DMG and app ZIP, SPDX inventory, separate
exact-version corresponding-source ZIP, checksums and provenance. Every binary recipient
must retain equivalent source access at no additional charge. Redistribution must preserve the exact
source asset and source offer; source, digest and tag retention is indefinite
until the distribution owner documents that all obligations have ended.

## Known limitations

This prerelease does not complete RFC-BPR-0038 release qualification. M8/M9
clean-account vault, native Intel/platform, crash privacy and vulnerability
qualification gaps remain open. Recorded Qt 6.11.2 vulnerability scans have
unresolved findings; signatures and notarization do not resolve them.

The intermittent file-selection race and earlier large-history responsiveness
timing failure remain unresolved unless new exact-version evidence establishes
otherwise. Tour publication depends on exact host and transport qualification.
Installed agents and GitHub CLI are separately configured capabilities. Profile
purge excludes shared updater and registry state and is not uninstall.

The release remains private and must be marked as a GitHub prerelease without
replacing the current stable Latest release. These preparation notes do not
claim that packages have been produced or published.
