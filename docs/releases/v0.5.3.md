## Changes since [0.5.2](https://github.com/MikeMarcin/BetterPullReview/releases/tag/0.5.2)

### New

- Ask an agent to update a pull request you authored from its target branch. The Status panel shows the update action alongside merge conflicts.

- Complete skill references when writing a follow-up in an item’s side chat.

### Changed

- Updated the bundled Qt runtime to 6.12.1.

### Fixed

- Tab and Shift+Tab indent and outdent selected code in the comment composer.
- Scroll through Comments with the pointer over a draft card or the empty drawer.
- The first click on the pull request update action opens agent setup when needed.
- Codex model choices appear as soon as they are available during Agent setup.
- Agent workspace setup reuses the existing repository cache for sparse checkouts.
