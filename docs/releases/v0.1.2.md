# BetterPullReview 0.1.2

Private macOS patch build for GitHub Enterprise Server testing with the
organization-standard GitHub CLI 2.45.0.

## Included

- GitHub CLI account discovery and API access now accept `gh` 2.45.0 and
  newer.
- `gh` 2.45 through 2.95 use the bounded, token-hidden human
  `gh auth status` response; 2.96 and newer retain JSON discovery.
- Only the active canonical hostname and login enter BetterPullReview.
  Masked-token, scope, protocol and credential-source text are discarded.
- Unsupported CLI versions, process failures and malformed account responses
  now produce distinct diagnostics.
- Universal Apple silicon and Intel application bundle, Developer ID signing,
  hardened runtime, Apple notarization and stapling.

## Release verification

At the owner's request, the release script's broader test gate was skipped for
this private testing build. Packaging still performs the tests-disabled
universal build, runtime-policy checks, Developer ID signing, notarization,
stapling, Gatekeeper assessment, relocated launch check and artifact checksum
verification.

## Known limitations

- Full Git comparison remains qualified only for `gh` 2.100.0 with Apple Git
  2.50.1. With `gh` 2.45.0, use this build to validate CLI account discovery,
  GHES identity and API connectivity; full diff loading may remain unavailable.
- GitHub CLI discovery reads the default `gh` configuration for the signed-in
  macOS user; custom `GH_CONFIG_DIR` overrides are not imported into the app.
- Reply submission and reconciliation against a live GitHub or GHES server
  remain under repair in BPR-0896.
