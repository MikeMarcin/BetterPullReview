# BetterPullReview 0.4.2

## Changes since 0.4.1

- Open pull requests progressively and keep Home usable immediately when returning.
- Refresh the file on screen first and update reviewer and thread state without reloading the whole pull request.
- Remember discussion and review comment filters across pull requests and launches.
- Show pull request draft state and let its author mark it ready for review.
- Notify about activity on your pull requests with a configurable desktop notification preference.
- Load GitHub Enterprise profile pictures through the authenticated avatars API, including CLI connections.
- Present agent failures as errors and wait for setup before offering suggested prompts.
- Offer Comment only when reviewing your own pull request.

## Prerelease verification

This early Mac/Windows prerelease precedes comprehensive native Release and Debug functional qualification. Its signed packages and exact corresponding-source, SPDX and checksum bindings are verified before publication. Full qualification and Ubuntu packages follow separately. Stable 0.4.1 remains Latest until the full release is complete.

Tested target environments are macOS 14.4+ universal, Windows 11 x64 and Ubuntu 26.04 under WSL2/WSLg. Other Windows and Linux versions may work but are untested.

## Corresponding source and known limitations

Each platform provides a separate exact corresponding-source archive, SPDX and checksums through the same release channel. Binary recipients retain equivalent source access at no additional charge, including corporate/offline redistribution. Source, digests and tags remain immutable and retained indefinitely until applicable obligations end. Qt and xdiff remain replaceable under their included licence and rebuild/relink instructions.

RFC-BPR-0038 remains open. Native installation, authentication, vault, accessibility, upgrade/removal, Intel execution, resident-material crash privacy, external hardening, allocator/fuzz and independent security-review gaps remain explicit. Profile purge excludes shared updater/registry state and is not uninstall. Fresh vulnerability findings and any applicable carried dispositions will be recorded against the actual delivered artifacts; prior release scans do not qualify this release.
