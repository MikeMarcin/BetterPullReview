# BetterPullReview 0.1.1

Private macOS patch build for validation against a real GitHub Enterprise
Server environment.

## Included

- A separate `Use GitHub CLI` sign-in path on Home and Accounts & hosts.
- Explicit discovery of every active account reported by the installed
  official `gh`, including GitHub Enterprise Server accounts that were not
  added to BetterPullReview first.
- Exact-host CLI account cards naming the observed login before connection.
- Token-free, bounded account discovery: BetterPullReview never asks
  `gh auth status` to show a token.
- Finder-launched app support for standard Homebrew and MacPorts `gh`
  locations.
- Universal Apple silicon and Intel application bundle, Developer ID signing,
  hardened runtime, Apple notarization and stapling.

## Test focus

This private testing build uses the focused GitHub CLI adapter, multi-scale Qt,
and application setup public-path checks. At the owner's request, the release
script's broader test gate was skipped to publish the test build promptly.

## Known limitations

- GitHub CLI discovery reads the default `gh` configuration for the signed-in
  macOS user; custom `GH_CONFIG_DIR` overrides are not imported into the app.
- Reply submission and reconciliation against a live GitHub or GHES server
  remain under repair in BPR-0896. Use this build to validate installation,
  launch, CLI account discovery, authentication, repository access and
  read/review workflows, but do not treat a live reply failure as a packaging
  or GHES-connectivity failure.
