# BetterPullReview 0.1.10

Private prerelease selected for macOS 13 or newer (universal Apple Silicon and
Intel), Windows 11 x64, and Ubuntu 26.04 x86_64. Distribution builds retain the
full agent and local automation capabilities.

## Included

This patch includes the 0.1.9 functionality and these repairs:

- Large pull requests reuse each distinct file's exact identity when indexing
  conversation panels and cards, reducing repeated work during loading.
- Enlarged native fonts keep full review-navigation group names and usable
  overview controls when a native scrollbar takes space from the sidebar.
- Refreshing a comparison while private drafts restore no longer leaves saved replies unable to be discarded.
- Home and Overview summarize waiting conditions more calmly, with details available in context.
- Home identifies each pull request's author alongside its title.
- Windows dependency configuration retains its selected build generator; the test build uses a correctly typed review-waiting count assertion.

## Verification and packaging

The macOS development responsiveness and launch courses pass the unchanged
100 ms pull-request-load input-gap requirement after the conversation indexing
repair. Focused conversation panel, cards and model contracts pass, including
repeated paths, byte-distinct paths, empty paths and refreshed path mappings.
The complete normal native Windows and Ubuntu gates and final versioned Mac
producer gate are still required; development measurements do not qualify
another architecture or native runtime.

The selected set requires signed macOS DMG and app ZIP, Windows MSI, Ubuntu DEB
and per-user archive, with SPDX inventories, separate exact-version
corresponding-source assets, checksums and provenance. Native trust, actual
runtime audits, source binding and downloaded artifact verification remain
required before release completion. Binary recipients must retain equivalent
source access at no additional charge, including matching redistribution;
source assets, source offers and tags remain immutable while obligations apply.

## Known limitations

This prerelease does not complete RFC-BPR-0038 qualification. Clean-account
vault, native Intel/platform, crash privacy and vulnerability qualification
require their exact acceptance evidence. Qt 6.11.2 scan findings remain under
source-backed applicability review, including independent security-owner
acceptance for Critical and High findings; signatures do not resolve them.

Installed agents and GitHub CLI are separately configured capabilities. Profile
purge excludes shared updater and registry state and is not uninstall. Tour
publication depends on exact host and transport qualification.

The release remains private and must be marked as a GitHub prerelease without
replacing the current stable Latest release. These preparation notes do not
claim that packages have been produced or published.
