# BetterPullReview 0.2.1

Private prerelease following 0.2.0. macOS universal packages are produced first;
Windows x64 and Ubuntu 26.04 x86_64 packages follow from the same committed
source. Full agent and local automation capabilities are retained.

## Changes

- Review drafts no longer consume persistent blank records merely by selecting
  lines. Authored drafts remain recoverable across head changes and restarts;
  draft creation and sharing between windows retain the correct identity.
- Opening a file in Review marks it Seen for the displayed epoch. Accept is
  available with one click and Command+Shift+A (Control+Shift+A on Windows/Linux).
- File navigation can leave an unavailable file, and change navigation follows
  the clicked source position. Resizing the diff divider keeps text vertically
  stable, including at fractional display scales.
- Center ribbon width is configurable from 16 to 256 logical pixels, with a
  28-pixel default, half the previous width.
- Appearance section banners use subdued theme surfaces, and open Settings
  windows follow theme changes.
- Home keeps row facts aligned when Cancel appears and prevents adding a
  GitHub CLI account while its remembered connection is loading.
- Files and Search tabs follow the Comments and Notes styling. Search side
  markers align at the left, navigation labels sit closer to their controls,
  unread-comment badges describe the current file, and the redundant visible
  Command+J button is removed while Threads and the shortcut remain available.

## Verification and distribution

The combined implementation passed ten focused integration checks before this
version bump. Each producer must run its normal native gate on the exact release
source before distribution packaging. Final test results, configured skips,
artifact digests and trust observations are recorded separately; these notes do
not claim packages have already been produced or published.

macOS targets macOS 13 or newer on Apple Silicon and Intel and requires Developer
ID signing, notarization, stapling and Gatekeeper assessment. Windows packages
require Authenticode signing; Ubuntu packages require the approved OpenPGP key.
Windows and Ubuntu availability is announced only after their artifacts are
verified and uploaded.

Each platform supplies its exact-version corresponding-source ZIP, SPDX inventory
and checksums alongside its binaries. The macOS source asset is
`Source-BetterPullReview-0.2.1-macos-universal-corresponding-source.zip`.
Source access at no extra charge and immutable retention remain ongoing
distribution obligations, including corporate/offline redistribution.

## Known limitations

This prerelease does not complete RFC-BPR-0038 qualification. Native clean-account
vault, Intel/platform, crash privacy and vulnerability qualification gaps remain
open. Qt 6.11.2 findings still require exact-version applicability dispositions;
signing and notarization do not resolve them. WSL2 production does not establish
clean Ubuntu desktop or Secret Service qualification. Profile purge excludes
shared updater and registry state and is not uninstall.

After restarting and reconnecting through GitHub CLI, an older tour draft may
not appear in the restored window; previously saved tour publication still
resumes. The original reported review-publication failure was not captured, so
its exact trigger remains unconfirmed despite the draft-lifecycle fixes.

The release remains private and is marked as a GitHub prerelease, preserving
the current stable Latest release.
