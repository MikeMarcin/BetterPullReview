# BetterPullReview 0.1.0

Private macOS test release for validation against a real GitHub Enterprise
Server environment.

## Included

- Universal Apple silicon and Intel application bundle.
- Developer ID signing, hardened runtime, Apple notarization and stapling.
- Private GitHub and GitHub Enterprise Server profile support.
- Native pull-request review, diff, discussion and local review-state flows.

## Known limitation

Reply submission and reconciliation against a live GitHub or GHES server remain
under repair in BPR-0896. Use this build to validate installation, launch,
authentication, repository access and read/review workflows, but do not treat a
live reply failure as a packaging or GHES-connectivity failure.
