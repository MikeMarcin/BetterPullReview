# BetterPullReview 0.1.6

Private macOS prerelease for early testing on macOS 13 or newer, with native
Apple Silicon and Intel binaries in one universal application.

## Included

- GitHub CLI connections select an account per connection, and Accounts & hosts
  lists the configured CLI accounts without switching global authentication.
- Unsent thread replies survive Refresh and restart. Replies to deleted threads
  stay available with a note explaining their missing target.
- Review tours can publish on qualified GitHub connections. Tour stop links open
  Files changed, and pending stop edits use GitHub's supported mutation path.
- Optional tour writing assistance can use Claude's existing sign-in.
- The review drawer supports Start a review, pending line comments, and explicit
  verdicts, with confirmation before deleting or discarding review work.
- Home selection, open feedback, line details, tooltips, drawer resizing, and
  Compose presentation include the latest accepted usability corrections.
- Cold comparisons read both sides concurrently, avoid repeated account probes,
  and cancel prepared diff work promptly.

## Package and verification

The development build completed and the full 684-test gate ran: 681 passed,
two failed, and the Debug cache-bytes check had its configured skip. A test-only
mouse helper name collided with the notification course's bypass guard; the
helper was renamed, and the notification course passed its focused rerun.
The large-history responsiveness course failed again on rerun: an epoch refresh
recorded a 101.6 ms event-loop interval against its 100 ms bound. Refresh
completion stayed within its 12-second budget. This timing failure remains
unresolved; it is not a passing performance claim.

The release workflow produces a tests-disabled universal application. Packaging
checks the restricted Qt runtime, both architecture slices and macOS deployment
floor, installed notices, and a relocated launch. The app and DMG require
Developer ID signing, Apple notarization and stapling, and Gatekeeper assessment
before publication.

The release includes a DMG, app ZIP, SPDX inventory, and a separate exact-version
corresponding-source ZIP, each with its own SHA-256 file. Keep source access
alongside binary access; redistribution must preserve the source offer and
the exact corresponding-source asset.

## Known limitations

This prerelease does not complete RFC-BPR-0038 release qualification. M8/M9
clean-account vault, native Intel/platform, crash privacy, and vulnerability
qualification gaps remain open. The recorded Qt 6.11.2 vulnerability scans
have unresolved findings; signing and notarization do not resolve them.

An intermittent file-selection race remains tracked for investigation in this
prerelease. Tour publication remains dependent on exact host and transport
qualification. Installed agents and GitHub CLI are separately configured
capabilities. Profile purge excludes shared updater and registry state and
is not uninstall.

This release remains private and is marked as a GitHub prerelease; it does
not replace the current stable Latest release.
