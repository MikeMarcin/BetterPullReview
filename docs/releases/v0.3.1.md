## Changes since 0.3.0

- Original BetterPullReview code and documentation now carry the MIT License.
  Packages include the original-code licence alongside retained third-party
  notices and licence obligations.
- Installation and first-review documentation is shorter, with direct platform
  downloads and a private vulnerability-reporting policy.
- Release publication explicitly supports the now-public repository while
  preserving destination, source, checksum and visibility guards.
- Linux package auditing recognises exact stripped upstream Qt images through
  their producer metadata while retaining first-party symbol checks.

This patch contains distribution, audit-tool and documentation changes; the
application's review behavior is unchanged from 0.3.0.

## Verification and distribution

Each platform supplies checksums, SPDX and a separate exact-version
corresponding-source archive. Binary and source access are public through the
same release channel at no additional charge. Corporate/offline redistribution
must include the exact source asset. Source, digests and tags are retained
immutably and indefinitely until all applicable obligations have ended.

macOS uses Developer ID signing and notarization. Windows uses a per-user MSI;
the runtime ZIP is an inventory archive. Ubuntu 26.04 uses a signed DEB and a
per-user archive requiring system dependencies; WSL2 production does not qualify
a clean Ubuntu desktop. Its private ICU 73.2 libraries retain pinned source and
recipient rebuild instructions.

## Known limitations

RFC-BPR-0038 remains open. Clean-account installation, authentication and
platform vaults, native Intel and full Windows/Ubuntu desktop courses,
accessibility, upgrade/removal, resident-material crash privacy, external
hardening and complete vulnerability/fuzz coverage remain incomplete.
Profile purge excludes shared updater/registry state and is not uninstall.

The Ubuntu optimized large-review RSS-growth failure tracked by BPR-1653 is
unresolved. The owner explicitly carries forward the exception for only the unchanged
216 MiB process RSS-growth predicate to v0.3.1. Its result remains failed; the
separate 64 MiB cache bound passes. A dedicated implementer will pursue a
causal repair after publication, preserving the original limits and course.
This exception waives no other test, native, signing, security or source obligation.
Exact artifact and security results are recorded separately; historical findings
and dispositions retain only their original scope.
