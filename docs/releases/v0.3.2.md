## Changes since 0.3.1

- Filter a pull request's review by individual commits or selected commit ranges
  from the new Commits tab. Filter chips show the active selection. When a hidden
  commit separates selected changes to one file, read each selected commit’s diff
  separately. After a force push, review offers to rematch hidden changes.
- Set generated files aside and filter the file list. The review reads
  `linguist-generated` from the head commit's `.gitattributes`; files you mark
  yourself keep their review state locally. Open a set-aside generated file’s
  diff when you need to inspect it.
- Ignore a pull request on Home and restore it from the collapsed Ignored list.
- Opening a pull request while Home discovery is loading takes priority.
  Discovery avoids repeated reads and batches retained pull-request refreshes.
- The `+` button opens a draft even when the pull request has no threads.
  Files and Repositories drawers have their own command keys, and Overview can
  jump to the top or bottom of its files.
- The update panel shows formatted release notes and can check public releases
  without a GitHub.com sign-in. Update settings retain that access choice.
- Preserve the latest selected line when a tab is still loading or the window
  closes immediately after navigation.
- Sensitive storage erasure remains complete in optimized builds.

## Verification and distribution

Each platform supplies checksums, SPDX and a separate exact-version
corresponding-source archive. Binary and source access are public through the
same release channel at no additional charge. Corporate/offline redistribution
must include the exact source asset. Source, digests and tags are retained
immutably and indefinitely until all applicable obligations have ended.

macOS uses Developer ID signing and notarization. Windows uses a per-user MSI;
the runtime ZIP is an inventory archive. Ubuntu 26.04 uses a signed DEB and a
per-user archive requiring system dependencies; WSL2 production does not qualify
a clean Ubuntu desktop. Its private ICU 73.2 libraries retain pinned source and
recipient rebuild instructions.

## Known limitations

RFC-BPR-0038 remains open. Clean-account installation, authentication and
platform vaults, native Intel and full Windows/Ubuntu desktop courses,
accessibility, upgrade/removal, resident-material crash privacy, external
hardening and complete vulnerability/fuzz coverage remain incomplete.
Profile purge excludes shared updater/registry state and is not uninstall.

The earlier Ubuntu RSS-growth failure is retained in BPR-1653. The owner
approved a 240 MiB process RSS-growth criterion alongside the independent
216 MiB live-heap limit, and the card's complete current-source course passed.
The v0.3.1 exception is not extended. This release's exact native resource,
artifact and security results require their own qualification.
Historical findings and dispositions retain only their original scope.

Installed source-offer clarification: a sentence describing private repository access remains from earlier releases. This release supplies binaries and their exact corresponding-source assets publicly through the same channel at no additional charge. The exact source URLs and digests, redistribution duties, original-channel fallback and indefinite immutable retention remain in force.
