# BetterPullReview 0.4.1 preview

This candidate follows the 0.4.0 stable release. macOS and Windows previews are
published before comprehensive qualification; they retain prerelease status and
do not change the stable update channel. Use the assets and exact build number
listed on the [release page](https://github.com/MikeMarcin/BetterPullReview/releases).

## Changes since stable 0.4.0

- Request a review from Overview's People section with a searchable reviewer
  picker. The app confirms the selected pull request and reviewers before writing.
- Filter Overview's Comments to new replies and hide resolved conversations.
- GitHub profile pictures appear with people, with an Avatars preference.
  Your own posts use your GitHub login.
- Links to lines in the pull request's repository can show their source as a
  compact snippet in comments and the reader.
- Tour stops read their rendered prose and code; use the pencil to edit.
  Published stops read as stops in comments, and the code plates step through
  the tour.
- Release candidates carry a global build number across marketing versions.
  Windows uses a newer per-machine MSI identity while retaining the UpgradeCode.

## Verification and known limitations

The selected environments remain macOS 14.4+ universal, Windows 11 x64 and
Ubuntu 26.04 x64 under WSL2/WSLg. Other Windows and Linux versions may work but
are untested. Full agent integrations and local automation are included.
Windows runtime ZIPs are inventory archives. Ubuntu per-user archives require
the declared system libraries.

Each platform supplies checksums, SPDX, exact provenance and a separate
corresponding-source archive. Source is publicly available alongside the binary
at no additional charge and must accompany corporate/offline redistribution.
Source, digests and tags remain immutable and retained indefinitely until all
applicable obligations have ended. Qt and xdiff remain replaceable under their
included licence and rebuild/relink instructions.

The owner carries matching prior waivers, including the known HarfBuzz and
Qt CBOR deferrals, subject to fresh exact-source/artifact rechecks. Raw
vulnerability scans retain their actual failing status and findings; no clean
security scan or new independent acceptance is inferred. The Qt known-issue
remediation route remains an official upstream Qt release. New unique unwaived
findings require their own disposition.

Comprehensive qualification follows the previews. Dedicated Debug timing
courses are omitted under the permanent owner policy, with no passing or
functional coverage credit; mixed-course timing failures and unreached checks
remain recorded. Functional failures and hangs require investigation.
Optimized Release timing/resource, compilation, source integrity and native
trust remain separate obligations.

RFC-BPR-0038 remains open. Complete ordinary-user installation, authentication,
vault, accessibility, upgrade/removal, native Intel, resident-material crash
privacy, external hardening, allocator/fuzz and independent-review limits remain
explicit. Profile purge excludes shared updater/registry state and is not
uninstall. Final results bind the actual candidate and every carried exception;
previews do not establish complete native or security qualification.
