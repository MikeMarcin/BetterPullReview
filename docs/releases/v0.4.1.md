# BetterPullReview 0.4.1 (build 8)

## Changes since 0.4.0

- Request reviews from Overview's People section with a searchable reviewer picker and confirmation before writing.
- Filter Overview comments to new replies and hide resolved conversations.
- Show GitHub profile pictures with an Avatars preference, and use your GitHub login for your posts.
- Preview linked repository lines as source snippets in comments and the reader.
- Read tour stops as rendered prose and code, and use the pencil to edit. Published GitHub comments use “PR Tour”.
- Resolve threads from Discuss and from closed or merged pull requests.
- Retain the chosen agent when opening a pull request or refreshing setup, and provide richer operation diagnostics.
- Carry a global build number across marketing versions. Windows retains the UpgradeCode and advances the per-machine MSI identity.

## Known limitations

Complete ordinary-user installation, authentication, vault, accessibility, upgrade/removal, native Intel execution, resident-material crash privacy, external hardening, allocator/fuzz and independent-review gaps retain their existing scoped dispositions. Profile purge excludes shared updater/registry state and is not uninstall. The bundled Review Cycle and tour discovery/refusal paths were exercised; live CLI authentication/provider reads remain outside current qualification, and the legacy fake-gh course has no passing credit.
