## Changes since [0.5.3](https://github.com/MikeMarcin/BetterPullReview/releases/tag/0.5.3)

### New

- Agent conversations continue at the latest head when new commits arrive. The workspace moves there and the conversation says so; if it holds edits, choose Rebase onto the new head, Keep my changes on a branch and move, or Ask the agent to reconcile.
- History in the Agent tab and in tour chats renames and deletes sessions, and Delete all sessions removes every one.
- Settings › Storage & privacy › Clear local data lists each kind of local data on one line with what it holds. Check several and clear them together; Reset agents… and a workspace's Remove… open it with their box checked.
- The side chat about a finding, draft or thread can read the pull request's code, so follow-up questions get answers grounded in it.
- The side chat about a finding, draft or thread keeps sessions in History, like the Agent tab and tour chats.
- Settings › Prompts has an editable Reconcile after an update prompt, which the agent follows when it reconciles your edits with a new head.
- On macOS, Settings › General › Software Update has an Update channel: Stable only, or Include prereleases. Check for Updates also offers a newer build of the same version.

### Changed

- Every chat with an agent has the same one-row header. History opens with New session, which is greyed with its reason when it would change nothing, and cost and turns are in an info tooltip.
- Every chat has the same composer: Send becomes Stop while a turn runs, and Queue or Steer when you type more, with Stop beside it.
- Previous and Next comment in the Comments drawer move through the current file's comments only and stop at its first and last.
- Go to draft and Go to comment open the item in Comments, selected and ready to edit, and a collapsed draft is easier to recognise.
- In the Agent tab, a report's findings chart and counts stand above its attachment.
- A proposed tour stop shows a pencil, a trash can and one action on a single row.

### Fixed

- A queued message leaves the pending list once its turn starts, instead of showing Sending until the reply ends.
- After new commits arrive, the next question in the Agent tab is no longer refused.
- Updating a suggested comment from its side chat also updates its Suggested change and the draft made from it.
- Links in reports and comments open on the first click, and the link you reach with Tab shows a focus ring instead of selected text.
- Only new and Hide resolved in the Comments drawer look dimmed when off and filled when on.
- The right drawer no longer scrolls sideways, cuts off buttons or overlaps rows at narrow widths.
- A draft made from a report opens whole in the Comments drawer instead of cut off at its foot.
- Text in agent replies and comments that is marked as code but is not code, such as a workspace name, is no longer coloured as code.

## Going back to an earlier version

This version stores some data in a form that 0.5.3 and earlier cannot read. If you go back to an earlier version after using this one:

- Agent sessions are not shown. They are kept in a new file of their own, which earlier versions do not know about. They reappear when you return to this version.
- Settings cannot be opened, because earlier versions refuse settings saved by a newer one.
- An agent workspace that this version moved to a newer head cannot be used.
