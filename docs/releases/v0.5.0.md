## Changes since [0.4.2](https://github.com/MikeMarcin/BetterPullReview/releases/tag/0.4.2)

### New

- Author mode prepares a local pull request draft from a worktree: keep it as you work, attach evidence, write the description and tour locally, then create the draft pull request from your pushed branch.
- Home shows whose move each of your pull requests is. When new commits return a pull request you approved, its review offers Seen beside Approve, or reads Approve again when GitHub dismissed your approval.
- Ask what changed since your last review, whether a comment was addressed, or for an explanation of the file you are reading.
- Quick asks are available from three places. Their reports open as a file tab, and Draft all turns a report's findings into draft comments.
- Queue follow-up messages and steer a running agent chat while it shows its activity.
- Create and share prompt macros, skills, agents and MCP servers. MCP servers are off by default and enabled per agent.
- Give an agent a scratch folder, with builds and tests only when you opt in.
- Settings › Profiles imports and exports chosen settings and themes as one .bprsettings file, with a preview; drop a settings file onto the window to import it.
- Draft Description, beside the description in Author, writes a Summary, What changed and How to test description you can edit.
- Writing style and Comment labels are editable in Settings › Prompts, so drafted comments carry Conventional Comments labels again.
- Share prompts as a prompt pack: importing a newer version updates the prompts you have not edited, asks about the ones you have, and offers to remove the ones the pack dropped.
- Connect an account in one setup flow on Home and choose which signed-in gh account each connection uses.
- The Commits tab shows how old each commit is, with the exact date in its tooltip.
- Explain these commits and Review these commits on the Commits tab's selection.
- A running agent turn shows what it has cost so far.

### Changed

- Opening a pull request from Home shows its page at once while the review loads.
- Publish a guided tour from a form; the tour's chat updates it in one turn, and arriving at a stop shows its code, which you accept like a file. A tour is now only its stops and never changes the pull request description.
- Settings exports are .bprsettings files only; older settings and .bprtheme files are not imported.
- Todo, typo and chore comments no longer count as blockers unless marked (blocking).
- Drafting a comment from a report keeps you on the report.
- Local notes are part of Comments, counted and searchable with your drafts.
- Links to the same pull request open in the app; links in a pull request body ask before opening.
- Agent findings survive reopening and restarts, and suggested comments can be posted directly or drafted all at once.
- On Windows, the tab strip is the title row and the tour and Overview tabs fit in Segoe UI.
- The dark palette gives comments, includes and macros clearer colours.
- A review opens with Files and Comments open instead of restoring the drawers the window last had.
- Links and the Draft label are easier to read on dark and high-contrast backgrounds.

### Fixed

- Saved agents are back for anyone who updated from build 63 or earlier after using an agent in a pull request. Builds 64 to 66 could not open the saved agent settings and showed an empty agent list; nothing was deleted, and this build reads them from the same file. If the saved agents ever can't be read, Settings › Agents now says so and names the file instead of showing an empty list.
- Opening an agent attachment brings it to the front from any mode.
- A message sent while the agent is finishing its previous turn waits for that turn instead of interrupting it.
- A review always opens fresh, and submitting a review always finishes or says why it could not.
- A running agent turn no longer ends silently before its work is done.
- Right-click no longer disturbs drag selection of a line draft on Windows.
- Opening another pull request no longer shows the previous pull request's queued messages.
- Stop all no longer stays up for a queue that is paused with nothing running.
- An agent can work on a pull request whose local clone is shallow, and a run that stopped before answering no longer shows a Report.
- What changed since my review works on reviews that hold only part of the history, leaves out merges of the base, and reads the earlier code only when you ask.
- The Overview's changed-since-my-review mark appears on reviews that hold only part of the history.
- Seen in a review closes the pull request the way Approve does.
- A reopened agent turn's byline says how the turn ended.
- In Author mode, a local draft shows its proposed changes while This update has none.
- The Details toggle in Source search shows its dots on Linux.
- Saving a held tour-chat message no longer crashes the app.
- Agents no longer read as not allowed while a pull request loads, or keep the previous pull request's host verdicts.
- A finished agent turn reloads as answered, not stopped.
- Enhance signs in through the custom agent that drafted the comment.
- A draft you click away from keeps its words, and Next and Previous comment visit your drafts in order.
- Submitting after the pull request is read again keeps held comments, and a refused submission says which check refused it.
- The review's blocker count includes drafts whose label implies blocking.
- Suggested-change diffs scroll sideways, long comments grow and then scroll, and a scroll gesture stays with the box it began in.
- Inline code in reports is coloured, including member access.
- A tour's stops line up with the drawer's left edge.
- Discuss's drill-down pill shrinks so the counts and Clear stay on one row.
