# BetterPullReview 0.1.8

Private prerelease prepared for macOS universal, Windows x64, Ubuntu 24.04
x86_64 and RHEL 10 x86_64. Publication requires the complete selected signed
artifact set from one committed source revision.

## Included

This patch includes the 0.1.7 functionality and these review corrections:

- Syntax highlighting survives repeated file navigation, including large files.
- Discuss threads open their matching inline comment in Review.
- Discuss comments expose their Review actions directly.
- The review bar keeps its summary and navigation slots stable during updates.

## Package and verification

Distribution builds disable tests and retain the full agent and local automation
capabilities. Each native producer must run its normal test gate before packaging.
Failures and configured skips must be recorded; this version does not inherit
the previous release's acceptance of test failures or skipped tests.

macOS requires Developer ID signing, notarization, stapling and Gatekeeper
assessment for its universal app and DMG. Windows requires timestamped Azure
Artifact Signing for the first-party executables and MSI. Ubuntu and RHEL
require the approved OpenPGP identity; RHEL also requires native RPM signing.
Final installer extraction, runtime audits, source binding and downloaded
artifact verification remain required before claiming release completion.

Each platform supplies its binary products, SPDX inventory, separate
exact-version corresponding-source archive, checksums and applicable native
signature/provenance assets. Every binary recipient must retain equivalent
source access at no additional charge. Redistribution must preserve the exact
source asset and source offer; source, digest and tag retention is indefinite
until the distribution owner documents that all obligations have ended.

## Known limitations

This prerelease does not complete RFC-BPR-0038 release qualification. M8/M9
clean-account vault, native Intel/platform, crash privacy and vulnerability
qualification gaps remain open. Recorded Qt 6.11.2 vulnerability scans have
unresolved findings; signatures and notarization do not resolve them.

The intermittent file-selection race and earlier large-history responsiveness
timing failure remain unresolved unless new exact-version evidence establishes
otherwise. Tour publication depends on exact host and transport qualification.
Installed agents and GitHub CLI are separately configured capabilities. Profile
purge excludes shared updater and registry state and is not uninstall.

The release remains private and must be marked as a GitHub prerelease without
replacing the current stable Latest release. These preparation notes do not
claim that packages have been produced or published.
