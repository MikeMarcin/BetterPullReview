## Changes since 0.3.4

- Edit a pull request's description as its author, and edit your own published
  comments and review bodies in place. Save checks for changes on GitHub before
  writing, and offers the newer text when a conflict is found.
- Overview uses the conversation drawer, with individual comments in the review
  timeline. Drafts appear in the right Home section; a newer review revision can
  return to the queue after a refused verdict.
- Ask an agent about a conversation with its exact context attached. Agent
  workspace recovery also recognizes objects held by a linked clone.
- Tour publishing shows progress. New stops start on their title, the wizard
  shows its three steps, and stop actions are clearer. The tour link leads the
  description and its brief stays in the description. Hidden differences carry
  a short explanatory note.
- Markdown improves GitHub parity for inline math, colours, text, strong
  emphasis, tabs and autolinks.
- Windows installs per machine in Program Files and launches the desktop app
  without a console window. Uninstall an earlier per-user copy before installing
  this MSI; the installer refuses to leave both scopes installed.
- Windows and Linux offer **Use GitHub CLI** at sign-in. These CLI connections
  can read the pull request; full Git-object comparisons through `gh` remain
  macOS-only. The platform warning describes this limit. Windows and Linux do
  not provide macOS's OS-enforced denial of `gh` file writes.
- The macOS app includes the `bpr` terminal for local automation and tour work.
  Packaging and native audit checks also cover its separate executable.

## Verification and distribution

Each platform supplies checksums, SPDX and a separate versioned
corresponding-source archive. Binaries and their exact source are publicly
available through the same release channel at no additional charge.
Corporate/offline redistribution must include the matching source asset.
Source, digests and tags remain immutable and are retained indefinitely until
all applicable obligations have ended.

The release route uses Developer ID signing and notarization on macOS, Azure
Authenticode on Windows, and the approved OpenPGP signing key on Ubuntu.
The Windows runtime ZIP is an inventory archive. Ubuntu's per-user archive
requires the declared system libraries; private ICU 73.2 keeps its pinned source
and recipient rebuild instructions. See the final release results for observed
qualification and trust rather than treating these mechanisms as complete
installation, security or privacy acceptance.

## Known limitations

RFC-BPR-0038 remains open. Native Intel execution, full ordinary-user
installation/authentication/vault/accessibility/upgrade/removal courses on the
selected platforms, resident-material crash privacy, external hardening and
complete vulnerability/fuzz coverage remain incomplete. Profile purge excludes
shared updater/registry state and is not uninstall.

The owner explicitly carried all matching previously waived release limitations
forward for v0.4.0. Actual failures and configured skips remain recorded; this
amendment supplies no passing observation. Debug performance timings are
permanently nongating, and the eight named dedicated Debug performance courses
are omitted without Debug passing or functional-coverage credit. Release timing,
resource acceptance, compilation, source/SPDX integrity and native trust remain
separate obligations.

Known scanner findings, narrow prior factual dispositions and their recheck or
expiry conditions remain explicit. The owner's Qt known-issue decision continues
until an official Qt release supplies the fix. Neither no scanner match nor
bounded fuzzing establishes complete allocator or application security coverage.
Fresh artifact scans and all native results will be recorded for this candidate.

The separate source assets are public alongside the binaries. An older sentence
in installed source offers describing private repository access does not narrow
that public access, the exact source URL/digest binding, equivalent no-charge
recipient access, redistribution duties or indefinite retention.
