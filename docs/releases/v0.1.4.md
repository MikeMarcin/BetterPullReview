# BetterPullReview 0.1.4

Private macOS prerelease for early testing on macOS 13 or newer, with native
Apple Silicon and Intel binaries in one universal application.

## Included

- Local Review Cycles: capture review rounds, track suggestions and responses,
  compare revisions, and hand granted rounds to an agent through `bpr cycle`.
- Guided review-tour authoring, source-bound stops and navigation, private
  tracking, and labelled conventional comments.
- A Conversations view for finding pull-request discussions, plus revised
  Overview keyboard navigation and tooltips.
- Appearance customization, whitespace controls, and refinements to settings
  and the diff workbench.
- Improvements to large-project responsiveness, Git workspace isolation,
  process cancellation, and review publication recovery.
- Native sign-in and online pull-request reading fixes for the tour CLI.

## Package and verification

The release workflow runs the development build and test gate, then produces
a tests-disabled universal application. Packaging checks the restricted Qt
runtime, both architecture slices and macOS deployment floor, installed
notices, and a relocated launch. The app and DMG require Developer ID signing,
Apple notarization and stapling, and Gatekeeper assessment before publication.

The release includes a DMG, app ZIP, SPDX inventory, and a separate exact-version
corresponding-source ZIP, each with its own SHA-256 file. Keep source access
alongside binary access; redistribution must preserve the source offer and
the exact corresponding-source asset.

## Known limitations

This prerelease does not complete RFC-BPR-0038 release qualification. M8/M9
clean-account vault, native Intel/platform, crash privacy, and vulnerability
qualification gaps remain open. The recorded Qt 6.11.2 vulnerability scans
have unresolved findings; signing and notarization do not resolve them.

Tour publication remains dependent on exact host and transport qualification.
Installed agents and GitHub CLI are separately configured capabilities.
Profile purge excludes shared updater and registry state and is not uninstall.

This release remains private and is marked as a GitHub prerelease; it does
not replace the current stable Latest release.
