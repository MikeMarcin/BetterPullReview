# BetterPullReview 0.2.2

Private Windows x64 prerelease following the macOS-only 0.2.1 release. Full
agent and local automation capabilities are retained. This release does not
replace or add assets to the published macOS 0.2.1 release; Ubuntu packages
are not selected for this release.

## Changes

- Restore current file selection and review actions after accepted refreshes,
  including submissions, labels, replies and review-tour navigation.
- Retain a confirmed reply-draft action while its private store is temporarily
  rebinding, and apply it only to the original current owner and revision.
- Reduce unnecessary split-diff repaint work while keeping native scrollbar
  edges, fractional scrolling and source Find geometry aligned.
- Check cancellation more frequently in the diff application host so stopped
  preparation leaves time to unwind within the existing return budget.
- Repair Windows fixture, process-containment and native test-producer issues
  without weakening authority checks, input budgets or rendering assertions.

## Verification and distribution

The interrupted Windows gate and its continuation account for all 705 tests:
703 passed, one cancellation failure and one configured Debug cache-bytes skip.
After the cancellation and scrollbar repairs, all 35 affected ordinary Windows
courses passed on the repaired code, including the complete diagnostic wrapper
and its unchanged 10 ms cancellation assertion. Twelve affected WSL portability
courses and affected Mac checks passed. The original failures and configured skip
remain in the verification records; this is not an uninterrupted full-suite pass.
The separate optimized Release cache-bytes course passed in 270.16 seconds.
Final package identities and native trust evidence are recorded separately
after production.

The release provides a per-user Windows MSI, runtime inventory archive, SPDX,
checksums, provenance and a separate exact-version corresponding-source archive.
The runtime archive is inventory evidence, not a qualified portable installation.
Equivalent source access at no extra charge, build/relink material and immutable
retention remain ongoing distribution obligations, including offline and corporate
redistribution.

## Known limitations

This prerelease does not complete RFC-BPR-0038 native or release-security
qualification. Clean-account Windows 10/11 installation, authentication, vault,
accessibility, upgrade/removal, crash/privacy and vulnerability qualification gaps
remain explicit. Signing does not resolve dependency findings or certify those
runtime courses. WSL portability checks do not establish Ubuntu desktop or vault
qualification. Profile purge excludes shared updater and registry state and is
not uninstall.

The release remains private and is marked as a GitHub prerelease, preserving the
current stable Latest release.
