# Pack-only implementation order

This document is an import aid, not a repository tracker. Do not copy it into
the live issue board. After import, issue folder placement and `depends_on`
front matter are the sole workflow authority.

## Milestone A — import and semantic contract

1. Import and plan the RFC.
2. Implement the pure publication-placement policy.
3. Bind exact source anchors and placement evidence without using Qt geometry.
4. Implement the canonical permalink representation.

## Milestone B — provider and recovery machinery

5. Add native-line and file-level GitHub wire contracts plus the exact
   unsupported-response classifier.
6. Add repository- and operation-scoped write-capability evidence.
7. Migrate durable recovery from one wire attempt to one logical publication
   with deterministic child attempts.
8. Implement native-first negotiation and the fail-closed fallback transition.

## Milestone C — round trip and product surface

9. Normalize fallback comments back to semantic anchors without hidden metadata.
10. Expose the same comment gesture on every eligible current-head source line.
11. Compose the complete path through the shipped application.
12. Prove automated security, restart, mixed-client, and database-loss behavior.

## Milestone D — direct evidence and closeout

13. Run the designated GitHub.com/GHES interaction and record native/fallback
    behavior.
14. Reconcile documentation and simplify.
15. Replay every acceptance criterion and close only after RFC-BPR-0008 is
    Auto-Verified.
