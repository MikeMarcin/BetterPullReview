# BPR-0771: Retire the locator, host picker, status banner and public-preview button from Accounts & hosts

- **Candidate.** Local `main`: promote `5df39c06`, claim `53de5f35`, source `284d1eac` (23 files), and this record in the finish commit. Nothing is pushed.
- **Result.** Accounts & hosts is now four things: the sentence, the standalone device panel (until `BPR-0773`), one `server_card` per configured host profile, and the enterprise servers editor (until `BPR-0774`). The host picker row, locator, status banner, public-preview strip and button, and `account_card` are gone. `github_session_panel` is a non-visual model. A pull request's load refusal is said under the Home bar with Copy details, and a session failure is said in its card. Evidence is under Evidence.
- **Carried to BPR-0772: one card per server, not per profile.** Compositions pair native HTTPS with GitHub CLI on the same hostname. RFC-BPR-0032 A1/A4 ask for one card per configured server with the host shown once, and RFC-BPR-0015 offers `GitHub CLI (uses your gh sign-in)` inside a host's account row. So the plan is:
  - Group profile options by hostname, native first. The presented profile is the active one on that host, else the selected one, else its native profile.
  - The header kind line is the page's only transport statement.
  - The CLI offer is a bordered button carrying the composition's label text. The trust warning names "this server" rather than the hostname.
  - Only the current card's Sign in is filled.
  - Prove A4 with a per-state visible-text inventory: host, login, transport and state word each appear once.
  - Repoint the `main.cpp` CLI stages to iterate CLI offers.
- **Carried to BPR-0773.** The device flow moves into the card's account row. The toolbar Account action (D5) still reads the standalone device panel. For a signed-in GitHub.com host, the manual-token path is currently reachable only through the window's Connect action.
- **Carried to BPR-0774.** The combo editor is replaced by enterprise cards with Remember and Forget, and the `main.cpp` saved-server stage is repointed.
- **Environment note for successors.** In this session, 16 self-test courses fail identically at HEAD `53de5f35`:
  - the keychain vault is unavailable to the sandboxed run;
  - the device panel course checks visibility of the hidden per-window Settings window;
  - agent finding composition and full-agent;
  - agent invocation composition;
  - the saved-server epoch seed;

- **Mandate r2 (Dif).** Accounts-page work neither blocks nor provides a bottom-left Dif. Today Dif sits in the Home landing illustration slot or in the AI tools slot. The home-page and appearance milestones own that move and its reconciliation with RFC-BPR-0031 (D1).

Route a pull-request load refusal to Home's bar notice with Copy details, a session failure to the server card's state, and any composed course that selected the retired objects to the bar, the card or the strip.
