# Observe complete cohort options on a cold configure

Cold native configuration wrote its release observation before core declared `BPR_CORE_SHA256_PORTABLE`. A warm configure correctly reports its effective `OFF`, so frozen 0.4.1 build 2 was refused on Mac and Windows before signing or package creation. The raw failed commands, source `c674b7038` and N2 receipt/cohort remain immutable; the changed complete configuration requires a new number.

## Acceptance

- AC1: Declare the existing portable SHA-256 option before release observation on cold configure without changing its default, selection, core dependency ownership or strict cohort comparison. A real cold and warm configuration exposes the same complete option set and value.
- AC2: Add a durable regression and verify the actual source through cold/warm CMake, focused release-build/core-boundary checks and documentation. Gather complete actual native producer observations for the successor; preserve failed N2, actual exits, source/configuration binding and monotone allocation.

## Verification and successor preparation

The existing OFF selection now appears before cohort observation, with no backend or flags change. The actual-source cold/warm regression passes on Mac, Windows and Ubuntu using the selected Ninja/Release graph. Full release-build contracts pass 17 cases; after correcting the regression's initial default-VisualStudio multi-config fixture, its selected native case passes on all three platforms. The initial fixture error and both refused N2 configurations remain recorded.

The maintained Mac command accepts an absolute existing build graph only under this checkout's build root with an exact source cache home. It keeps normal frozen configure/toolchain/options/architecture checks and fresh artifact directories. Exact-source source/package/publisher/notary contracts pass 29 cases, including foreign/missing/relative/escaped graph refusal; six focused graph/notary cases and four core/architecture boundary courses pass. No graph is moved or symlinked.

All three actual complete distribution observations now contain the same 15 explicit feature options, including portable SHA OFF, with native compiler/SDK/settings recorded under the external run root. New N3 allocation is required; N2 is never repaired in place, signed, published or reused as the successor. The unsealed Mac compilation graph may retain its paths through the guarded argument. Full product qualification remains pending after previews.
