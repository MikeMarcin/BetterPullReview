# Record designated GitHub.com and GHES off-hunk publication evidence

Use the attended designated-live mutation course to establish the exact native-supported and legacy-unsupported behavior needed for closeout.

## Acceptance

- A named safe GitHub.com PR receives one off-hunk user-approved publication through the exact production operation; request/response classification and resulting representation are recorded without secrets.
- A named safe legacy GHES PR, or separately approved exact recorded contract, supplies the definitive unsupported shape and file-comment/permalink publication.
- GitHub-only web inspection confirms code context, full prose, author identity, reply behavior, and ordinary conversation continuity for both representations.
- No disposable probe comment, undesignated target, private code capture, credential, cookie, proxy detail, or IP-bearing raw evidence is retained.
- Evidence is bound to exact commit/path/line/comment IDs and the producing application/build identity.

## Verification

Record the focused command or attended interaction, result, durable evidence,
and producing commit on the live card. Reuse passing evidence only when its
inputs did not change. Run composition-oriented selectors for any slice that
changes the shipped path.
