# BPR-1675: Measure the complete release rehearsal and remaining budget gap

## Acceptance criteria

- AC1: Extend existing wrappers with one honest request phase ledger, actual child results and cheap readiness/failure controls; no hidden prewarming or timer resets.
- AC2: Run one stabilized native integration and the authorized mechanical producer rehearsal, recording complete work, cache condition, actual artifacts, prior evidence and pending decisions.
- AC3: Report measured request-to-result elapsed time and the remaining thirty-minute gap. Preserve all M8/M9, vault, crash, vulnerability, native and licensing limits. No signing/publication/version change is authorized by this card.
