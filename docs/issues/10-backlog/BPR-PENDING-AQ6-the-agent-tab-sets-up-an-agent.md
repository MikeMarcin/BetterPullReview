# BPR-PENDING-AQ6: The Agent tab sets up an agent in place, in every state of the frames

RFC-BPR-0091 M6 ([RFC](../../rfcs/RFC-BPR-0091-agent-first-run-setup.md#milestones)), owner answer Q1 A.

## Scope

- The setup in place of the conversation: Agent, Repository, Check it works
  and Ready, with folded steps, every state of the
  [design frames](../../design/BPR-PENDING-AN-agent-setup-v1/index.html),
  light and dark, and **What the agent gets**.
- History's **Set up agent…** and **Change repository folder…**; Settings ›
  Agents & context's **Set up agent…**, Codex program path, Codex protocol and
  plain-text harness rows; Settings › Repositories' clone folders, linked
  clones and worktree usage.
- The partly set up callouts and a later Ask's setup failures with their
  recovery and Check again.

## Acceptance criteria

- AC1: RFC AC01 and AC11 offscreen, light and dark.
- AC2: RFC AC12.
