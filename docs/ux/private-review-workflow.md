# Private review

The Agent tab's **History > Show every run…** lets you think through a pull request
privately, alone or with an agent, and publish only what you choose.

- Private history stays on this computer. Nothing private is added to a
  published comment.
- An agent sees only the sources you select and send with **Ask agent using
  only selected sources**.
- **Squash selected sources to draft…** turns selected history into an
  ordinary draft with **Accept as Draft**. Nothing changes on GitHub until you
  choose **Publish** in the draft editor.
- Edits never overwrite history; each one adds a revision.
- A comment is saved as a draft once you edit it. You can have 64 unpublished
  drafts per pull request.
- Deleting private data never deletes a GitHub comment.

> [!WARNING]
> If a comment's publication is unconfirmed, use **Retry publication** in its
> draft editor rather than posting it again, or the comment may appear twice.
> The retry keeps the same publication and reconciles what was already sent.
> **Finish review > Saved comments…** lists such a comment as **Publication
> unconfirmed**.

Publishing from private history has not yet been verified against live
GitHub.
