# Private review

**Review > Agent > Private history** lets you think through a pull request
privately, alone or with an agent, and publish only what you choose.

- Private history stays on this computer. Nothing private is added to a
  published comment.
- An agent sees only the sources you select and send with **Ask agent using
  only selected sources**.
- **Squash to Draft** turns selected history into an ordinary draft. Nothing
  changes on GitHub until you choose **Publish**.
- Edits never overwrite history; each one adds a revision.
- A comment is saved as a draft once you edit it. You can have 64 unpublished
  drafts per pull request.
- Deleting private data never deletes a GitHub comment.

> [!WARNING]
> If a publish shows as pending, use **Check status** in **Finish review >
> Saved comments** rather than posting again, or the comment may appear twice.

Publishing from private history has not yet been verified against live
GitHub.
